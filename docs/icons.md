# Icons

_Generated by `scripts/build.py` from `icons/icons.json`._

Default set from **Lucide** 1.55.0 (ISC license, kept in `icons/lucide/LICENSE`). 63 icons on a 24px grid; they use `currentColor`, so color them with a text/icon color token.

Sizes: use `sizing/4` (16), `sizing/5` (20) or `sizing/6` (24).

## In Figma

Components are named `lucide:<name>` (Icons frame). Each is 20x20 with a single filled vector layer named `shape` (the 1.5px stroke converted to a shape) bound to `neutral/20`. Keep the layer name `shape`: component and state overrides recolor it, and they survive swapping to another icon only if the name matches. Icon slots in components (button, link, tag, table, list-item, toast, toggle) are instance-swap properties that default to `lucide:star` and offer this set as preferred values.
